DocuMind AI — Retrieval-Augmented Generation Demo

Upload PDF documents to query content using TF-IDF passage retrieval and grounded answer synthesis with page citations.

  1. Upload: Choose a PDF file (up to 10 MB). Text pages are extracted and split into attributed chunks.
  2. Scope: Choose All Documents to search across your full collection, or select an individual document to restrict retrieval.
  3. Ask: Enter a question below. The system retrieves the top matching passages and generates a grounded response.
  4. Verify: Review the page-level citations and expand the source passage accordions to verify the source text.
  5. Grounding: If the question cannot be answered from the document, the system strictly returns: The document does not contain this information.
